# AIM and Messaging

AIM stand for Aeronautical Information Management which include the ff:
- AMHS: Aeronautical Fixed Telecommunication Network
- AFTN: Aeronautical Message Handling System
- SWIM: System Wide Information Management
- AIXM: Aeronautical Information Exchange Model

**Big Picture Comparison**

| Technology | Role Type | Analogy | Data Style |
| :--- | :--- | :--- | :--- |
| AFTN | Network Network | Old-school Telex or Fax machine | Plain, short text string |
| AMHS | Network Network | Secure, enterprise email system | Large text files with attachments |
| AIXM | Data Language | A universal database layout format | Structured XML/GML geospatial code |
| SWIM | Network Architecture | Modern Cloud Platform / Web API | Live stream / Publish-subscribe data |
